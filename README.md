# Beacon — Uptime & Error Monitoring

Beacon is a modern monitoring platform designed for engineering teams. It watches your APIs, background jobs, and front-ends to catch regressions in seconds and route alerts to the right engineer.

![Beacon Logo](data:image/svg+xml,%3Csvg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'%3E%3Cpath d='M12 2 L20 20 L12 16 L4 20 Z' fill='%23b18cff'/%3E%3C/svg%3E)

## 🚀 Features

- **Synthetic Uptime Checks**: Probe endpoints every 10 seconds from 14 regions.
- **Error Grouping**: Root-cause fingerprinting that reduces alert fatigue.
- **Deploy-Aware Timelines**: Correlate performance spikes with specific commits and authors.
- **On-Call Routing**: Integrated escalation to Slack, PagerDuty, and SMS.
- **Branded Status Pages**: Automatically updated public status pages.
- **Privacy First**: PII scrubbing and SOC 2 Type II compliance.

## 💻 Technical Highlights

- **Aesthetic UI**: Modern dark theme with Aurora effects and grid-grain backgrounds.
- **Smooth Animations**: Uses `IntersectionObserver` for scroll-triggered reveal animations.
- **Responsive Design**: Mobile-first navigation and flexible grid layouts.
- **Modern Typography**: Integrated with Fontshare (Clash Display, Cabinet Grotesk, Satoshi).

## 🚦 Getting Started

To view the landing page locally:

2. Open `index.html` in any modern web browser.
3. (Optional) Use a local server extension (like VS Code Live Server) for the best experience.
